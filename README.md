> Четыре–шестнадцать человек, три режима, одна ночь. Свет — это жизнь, и его всегда мало.

## Режимы

**Фонарщики** · 2–16 · PvPvE
Четыре костра, дрова, рассвет через 10 минут. Раз в минуту один игрок становится Тенью:
его фонарь гаснет, костёр он может погасить. Тень ловится чужим лучом. На рассвете по мосту
уходит столько людей, сколько костров уцелело.

**Эстафета света** · 2–16 · кооп
Один фонарь на всех, 200 блоков леса, Собиратель идёт на свет. Передавайте фонарь, кричите,
ставьте ложные огоньки и донесите его до алтаря в часовне. Разбить фонарь — уйти самому.

**Постоялый двор** · 3–16 · дедукция
Дом из девяти комнат, пять циклов по 75 секунд: гаснет свеча, запирается комната, приходят
улики. Один из вас — «не гость». Голосования, подвал, финальное обвинение.

## Быстрый старт: сервер Minecraft

```bash
cd minestom
./gradlew run          # Java 25, порт 25565, offline-mode
```

Клиент — **Minecraft Java 26.3**, адрес `localhost` (или IP машины).
В игре: `/h create lantern` → друзьям `/h join КОД` → `/h start`.
Подробности, управление и оговорки — в [`minestom/README.md`](minestom/README.md).

Проверить правила без Minecraft:

```bash
cd minestom && ./gradlew selfTest     # 30 проверок трёх режимов
```

## Быстрый старт: браузерный хаб (быстро позвать друзей)

```bash
cd party
npm install
npm start             # http://localhost:3000
```

Хозяин создаёт комнату, кидает друзьям ссылку и 4-значный код, добивает состав кнопкой
«+ БОТ», жмёт «Готов» — и раунд идёт по тем же числам, что и в Minecraft.
Протокол плейтеста (что смотреть, что записывать) — в [`party/README.md`](party/README.md).

## Почему две реализации

Правила и баланс удобно крутить в браузере: десять секунд до раунда, боты, логи.
Перенести готовые числа в Minecraft — работа `minestom/`: игровое ядро
(`ru.nochfonarey.core`) вообще не знает про Minestom, поэтому одни и те же
`LanternMode` / `RelayMode` / `InnMode` гоняются и в self-тесте без клиента,
и в живом мире через слой `ru.nochfonarey.mc`.

Minestom **26.3 ещё не в Maven Central** (PR `feat: 26.3` открыт, последний релиз —
`2026.10.07-26.2`), поэтому сборка тянет ветку `26_3` через JitPack либо из
`publishToMavenLocal` — см. README в `minestom/`.
