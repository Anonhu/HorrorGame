# ЛЕС СЛУШАЕТ · LES SLUSHAET

> Хэллоуин-хоррор на **Minecraft 26.3 «Wilderness Bound»** (Minestom).
> Он не видит тебя. Он слышит. И двигается, когда ты не смотришь.

Репозиторий содержит **два** связанных прототипа одной игры:

| Что | Где | Статус |
|---|---|---|
| 🎮 **Играбельный 3D-срез** (браузер, Three.js) | `web/` | ✅ работает, можно играть прямо сейчас |
| ⚙️ **Сервер Minestom 26.3** (Java 25) | `minestom/` | 🧱 полный каркас геймплея, нужна сборка у себя |
| 📐 **Дизайн-док** первого прототипа | [`DESIGN.md`](DESIGN.md) | ✅ |
| 🎪 **Мультиплеерные концепты** на 4–16 игроков | [`design/README.md`](design/README.md) | ✅ |

## Зачем два прототипа

Minestom **26.3 ещё не зарелизен** (PR `feat: 26.3` открыт, последний релиз на Maven Central — `2026.10.07-26.2`).
Поэтому проверяемого «здесь и сейчас» результата на Java не получить: нужен Java 25, Gradle и Maven Central.
Браузерный срез — это **та же игра, те же правила и тот же визуальный язык**, которые можно проверить за 10 секунд.
Java-версия переносит эту механику в настоящий Minecraft, блок-в-блок из 26.3 (поплары, грибы-полки, соломенные кровати, тыквы, заброшенные лагеря).

## Быстрый старт: браузерный срез

```bash
cd web
npm install
npm run dev      # http://localhost:5173
```

Управление: **WASD** — идти, **Shift** — бежать, **Ctrl** — красться,
**мышь** — смотреть, **E / ЛКМ** — эхо-импульс, **F / ПКМ** — фонарь, **Esc** — пауза.

### Что уже есть в срезе

- **Процедурный лес попларов** — 640 бледных стволов, 4 оттенка листвы (кровавая/золотая/янтарная/пепельная), падающая листва, туман-ленты, светляки.
- **Небо с авророй и луной** — отдельный shader-купол: полярные сполохи, звёзды, облачные полосы, ореол луны.
- **Полый Олень** — собран из коры и костей: клетка-рёбра с углями внутри, ветвистые рога, тряпки мха. Уникальный ИИ (см. ниже).
- **Четыре тотема** — зажигаются, если стоять в круге и не двигаться; после четвёртого — обряд в центре леса.
- **Кровавая листва** ведёт от тотема к тотему (и это единственный навигационный ориентир).
- **Эхо-импульс** — сонар: волны, призрачные стволы, метки тотемов, силуэт Оленя. Стоит шума.
- **Процедурный звук** без единого аудиофайла: ветер, дрон, «гобойный» рёв Оленя, шёпот, сердцебиение, костяные колокольчики. Микс адаптируется к опасности.
- **Filmic-слой**: зерно, винье́тка, скан-линии, леттербокс, вспышки, freeze-frame при взгляде на Оленя.
- HUD: компас с меткой цели, шум, «взгляд», фонарь, сердца, субтитры-шёпот.

## Три правила Полого Оленя

1. **Тишина — жизнь.** Бег = 80 шума, шаг = 26, красться = 6, фонарь добавляет постоянные +5. Шум — это приманка.
2. **Взгляд — не оружие.** Пока смотришь — он замирает (freeze-frame, экран звенит).
   Дольше **3.4 секунды** — бросок. Это ловушка: смотреть можно только чтобы выиграть время.
3. **Эхо — единственный удар.** Импульс в радиусе 44 блоков станит его на 5 секунд. И шумит на +30.

Плюс «правило невидимки»: он двигается **только пока на него не смотрят**, и замирает ровно в тот кадр, когда попадает в конус взгляда.

## Minestom 26.3: сборка

```bash
cd minestom
gradle run        # или ./gradlew run, если добавите wrapper
```

Нужен **JDK 25**. Зависимость тянется из JitPack с ветки `26_3`:

```kotlin
implementation("com.github.Minestom.Minestom:minestom:26_3-SNAPSHOT")
```

Если JitPack не собрал ветку — переключите одну строку в `build.gradle.kts` на стабильную
`net.minestom:minestom:2026.10.07-26.2`: игровой код написан на общем для 26.2/26.3 API.
Подробности и карта файлов — в [`minestom/README.md`](minestom/README.md).

Что уже реализовано в Java-версии:
- генератор леса на 26.3-блоках (`POPLAR_LOG`, `RED_POPLAR_LEAVES`, `POPLAR_SHELF`, `STRAW_BED`, `JACK_O_LANTERN`…);
- статический план мира (4 тотема, 3 заброшенных лагеря, тропа из листвы) — общий для генератора и геймплея;
- тотемы с прогрессом «стой и не двигайся»;
- Полый Олень: невидимая сущность, которой управляет собственная логика восприятия, «статуя» из частиц, оглушение эхом;
- шум, sidebar, actionbar, титры, звуки, эхо-волны из частиц.

## Мультиплеерные концепты (4–16 игроков)

Три проработанных режима с числами, картами, балансом, MVP и техническими рисками:

- **[ФОНАРЩИКИ](design/01-lanternkeepers.md)** — PvPvE, 10 мин. 4 костра, дрова, случайная «Тень» на 30 секунд.
  Сколько костров дожило до рассвета — столько людей уйдёт по мосту. Финал: голосование, кто останется.
- **[ЭСТАФЕТА СВЕТА](design/02-light-relay.md)** — кооп, 20 мин. Один фонарь на всех: передавать, ронять, заряжать у костров.
  Финал: разбить фонарь — и тот, кто это сделал, остаётся.
- **[ПОСТОЯЛЫЙ ДВОР](design/03-inn.md)** — социальная дедукция, 10 мин. Свечи, замки, улики, «не гость».
  Проверяется на бумаге до написания кода.

Сводка, сравнение и общий технический фундамент (свет в Minestom, лобби, голос, антигриф):
[`design/README.md`](design/README.md).
