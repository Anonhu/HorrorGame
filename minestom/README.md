# ТРИ НОЧИ · сервер Minecraft 26.3 на Minestom

Полноценный мультиплеерный сервер: заходите настоящим клиентом **Minecraft Java 26.3**
(«Wilderness Bound»), выбираете режим и играете втроём–шестнадцатером.
Браузерная версия из `party/` осталась как плейтест-стенд правил — здесь те же числа,
но всё происходит в мире Minecraft.

```
minestom/
├── src/main/java/ru/nochfonarey/core/   игровое ядро без Minestom (можно тестировать без сервера)
│   ├── LanternMode.java                 «Фонарщики»      — костры, дрова, Тень, рассвет
│   ├── RelayMode.java                   «Эстафета света» — один фонарь, Собиратель, алтарь
│   ├── InnMode.java                     «Постоялый двор» — свечи, комнаты, улики, «не гость»
│   ├── Lobby.java                       раскладка площади: круг, арки, палый лес, стена от пустоты
│   ├── RoomLobby.java                   комнаты ожидания для трёх режимов
│   ├── Blueprint.java                   «куда строить»: мир или превью-картинка
│   ├── Room / GameServer / Mode / P     комнаты, коды, тик, состояние игрока
│   └── SelfTest.java                    41 проверка правил, без Minecraft
├── resourcepack/                       PS1-текстуры 16×16 + встроенный core-шейдер
├── shaderpack/                         PS1-шейдеры Iris/OptiFine (lite и full)
└── src/main/java/ru/nochfonarey/mc/     слой Minecraft
    ├── Main.java                        точка входа, порт 25565
    ├── Hub.java                         комнаты, тик 20 Гц, HUD
    ├── McBlueprint.java                 Blueprint поверх настоящего мира Minestom
    ├── Ambience.java                    дым, искры и звук площади
    ├── NetHost.java                     реализация Host: блоки, свет, звук, телепорт
    ├── Hud.java                         сайдбар и строка над хотбаром
    ├── Interact.java                    вход, чат, ПКМ, Shift, голосование
    ├── Cmd.java                         /h create|join|start|reset|code|vote|leave
    └── BlockMap.java / Items.java / Worlds.java
```

## Что нужно

* **Java 25** (Minecraft 26.3 требует именно её).
* Клиент **Minecraft Java 26.3**. Лицензия не нужна: сервер в offline-режиме.
* Первый запуск качает зависимости (Minestom ветки `26_3` через JitPack) — нужен интернет.

## Запуск

```bash
cd minestom
./gradlew run        # JDK 25 подтянется сам, если его нет
```

Порт `25565`, либо переменная окружения `PORT`:

```bash
PORT=25566 ./gradlew run
```

Если JitPack не отдаёт `26_3-SNAPSHOT` (в `build.gradle.kts` есть вторая строка
для координаты `com.github.Minestom:Minestom`), соберите Minestom локально:

```bash
git clone -b 26_3 https://github.com/Minestom/Minestom.git
cd Minestom && ./gradlew publishToMavenLocal
# дальше в minestom/: ./gradlew run  (mavenLocal() уже первым в repositories)
```

Проверить игровую логику без Minecraft:

```bash
./gradlew selfTest
```

То же самое **без Gradle** — если Gradle/Maven/JitPack недоступны (закрытая сеть,
офлайн-машина). Скрипт сам скачает JRE (PyPI) и ECJ (npm), скомпилирует проект
вместе с заглушками API и прогонит `SelfTest`:

```bash
python3 tools/verify_stubs.py     # каждая заглушка есть в настоящем API 26.3
bash tools/build_offline.sh       # ECJ-компиляция (95 файлов) + SelfTest
python3 tools/check_ui.py         # предмет меню, инвентарь лобби, свеча, события
```

## Как начать играть

1. Зайдите в свой мир? Нет — зайдите **на сервер** `localhost` (или IP машины), версия 26.3.
2. Вы на ночной площади: в центре костёр, по кругу три арки — Фонарщики, Эстафета, Двор.
   `/h create lantern` (или `relay`, `inn`) — вы хозяин комнаты, вам дали код из 4 цифр.
3. Друзья: `/h join 1234`. Код виден в `/h code`.
4. Хозяин: `/h start`. Всё, раунд пошёл.

В руках один предмет — компас **«Меню режимов»**: ПКМ или `F` открывают меню из трёх
пунктов, клик по пункту создаёт комнату. Меню также показывается само при входе на
площадь и открывается командой `/h menu`; `/h` без аргументов — справка.

## PS1-стиль: текстуры и шейдеры

Сервер сам поднимает раздачу на порту **8123** (`PACK_PORT`) и при входе присылает
клиенту ресурспак:

| | |
|---|---|
| `http://localhost:8123/` | страничка со ссылками |
| `http://localhost:8123/pack.zip` | PS1-ресурспак: 16×16, 15 бит, 36 блоков + 7 предметов |
| `http://localhost:8123/shaders/ps1-full.zip` | шейдер Iris/OptiFine: джиттер, сканлайны, дрожание вершин |
| `http://localhost:8123/shaders/ps1-lite.zip` | то же без вмешательства в геометрию |

Текстуры генерируются из палитры кодом — `bash tools/make-assets.sh` пересобирает
и PNG, и оба zip. Подробности: [`resourcepack/README.md`](resourcepack/README.md),
[`shaderpack/README.md`](shaderpack/README.md), превью — `resourcepack/preview.png`
и `shaderpack/preview.png`.

## Управление

| | |
|---|---|
| **Shift (присесть) и держать** | главное действие: кормить костёр, заряжать фонарь, держать алтарь, забирать гостя |
| **ПКМ** | то же самое коротким нажатием (0.5 с) |
| **F (свап)** | лобби — меню режимов · «Эстафета» — передать фонарь · «Двор» — зажечь свечу рядом |
| **ПКМ по свече** | «Двор»: меню голосования (во время голосования) |
| **/h vote ИМЯ** | голос текстом |
| **чат** | слышит только ваша комната |

Блоки в adventure-режиме не ломаются: всё взаимодействие — через Shift/ПКМ рядом с объектом.

## Режимы

### Фонарщики (2–16)
Четыре костра на поляне, двенадцать кучек дров. Фонарь тратит заряд, у костра заряжается,
дровами костёр поддерживается. Раз в минуту один из игроков становится **Тенью**: его свет
гаснет, а у костра он может погасить огонь (5 с) — тогда из земли полезут «Тянущиеся»,
которые хватают людей на 8 с. Тень ловится лучом чужого фонаря (11 блоков, 33°, 1.6 с).
Через 10 минут — рассвет и голосование: уйти по мосту смогут столько человек, сколько
костров ещё горит.

### Эстафета света (2–16)
Один фонарь на всех. Несущий светится, остальные видят на пару шагов. Фонарь садится,
заряжается у трёх костров (по 25 %). `F` — передать ближайшему, `F` не у несущего — крикнуть
и поставить ложный огонёк (приманка на 4.5 с). **Собиратель** идёт на свет и на крик;
у костра он не суётся. Финал — часовня на востоке и алтарь: подержи Shift 3 секунды,
фонарь разобьётся, и несущий останется в лесу.

### Постоялый двор (3–16)
Дом 3×3 комнаты, двери, свечи. Пять циклов по 75 секунд: одна общая свеча гаснет, случайная
комната запирается (но проход в зал остаётся всегда), всем приходят улики — правдивые и
ложные. Каждые 75 секунд — голосование: большинство отправляет человека в подвал на цикл
(он не может действовать). Один игрок — **«не гость»**: Shift рядом с гостем без свидетелей
(7 блоков) 4 секунды — и тот исчезает. Два раза забрал — победил. После пятого цикла —
финальное голосование, кто не гость.

**Свечи — это механика, а не декорация.** Личный огонёк гостя тает сам (`p.candle`),
у горящей общей свечи он восстанавливается. Потухшую общую свечу зажигают обратно:
одно нажатие `F`/ПКМ рядом с подсвечником или удержание Shift полторы секунды.
Если в доме не горит ни одна свеча, свидетели перестают спасать жертву (радиус
падения 7 → 3 блока), а «не гостю» на добычу нужно 2,4 с вместо 4 — темнота работает
на него. Зажечь свечу может и «не гость»: это лучшая маскировка. Счётчик
«Свечи: 2/4» и полоска личного огонька висят в боковой панели.

## Ночные события: почему раунды не одинаковые

В начале каждого раунда в чат приходит прогноз — **«Ночь обещает: ВЕТЕР · ТУМАН · ШЁПОТ»**,
дальше события идут по часам (первое через 35–50 с, потом каждые 40–65 с, пока набор
не кончится). У каждого — реальный эффект, а не только строчка текста:

| Режим | Событие | Что делает |
|---|---|---|
| Фонарщики | ВЕТЕР | костёр теряет 30 топлива — его надо срочно докормить |
| Фонарщики | ТУМАН | 30 с фонарь садится вдвое быстрее |
| Фонарщики | ШЁПОТ | лес называет костёр, у которого сейчас Тень |
| Фонарщики | СТАЯ | из земли поднимаются два лишних Тянущихся |
| Эстафета | ГРОЗА | молния выжигает 25 % заряда общего фонаря |
| Эстафета | ПОГОНЯ | Собиратель на 30 с становится в 1,55 раза быстрее |
| Эстафета | СЫРОСТЬ | 25 с заряд тает сам, даже в руках |
| Двор | ХОЛОД | у всех гостей сразу −25 личного огонька |
| Двор | СКРИП | пол шёпотом выдаёт одну внеочередную улику |
| Двор | СКВОЗНЯК | ещё одна общая свеча гаснет |

Следующее событие и последнее случившееся видны в боковой панели, так что к нему
можно готовиться, а не узнавать о нём из испуга.

## Точная поддержка 26.3

Всё, что привязано к версии, сверяется скриптами против настоящих исходников:

## Мир: пустота, стены и возврат на спавн

Все миры сервера генерируются **пустыми**: у площадки нет «поля» вокруг, только
то, что построила игра. Раньше генератор заливал камень от -64 до 62, и площадь
стояла посреди плоского каменного мира — с неё можно было уйти в никуда.

* по кромке площади и каждой комнаты ожидания стоит невидимая стена
  (`minecraft:barrier`, кольцо 2,4 блока — без диагональных щелей; её считает
  `Lobby.WALL_R` / `RoomLobby.WALL_R`);
* упал ниже `Hub.VOID_Y` (45) — вернули на спавн: на площади это южный край,
  в комнате — спавн арены, режим и роль при этом не сбрасываются;
* если игрок всё-таки оказался вне стены или в старом мире комнаты — его
  возвращает туда же `Hub.guard()`, который крутится каждый тик;
* проверить геометрию без клиента: `SelfTest` стреляет 360 лучами в стену
  и ни разу не находит щели, а `python3 tools/preview-lobby.sh` рисует остров
  со всех сторон.

Старт раунда переставлен: сначала строится **вся арена** в свежем пустом мире,
и только потом игроков туда переносят. Если карта не построилась (исключение
или меньше 500 блоков), `/h start` откатывает всё и возвращает людей в комнату
ожидания с сообщением, а не оставляет их в пустоте. Количество поставленных
блоков печатается в чат и в консоль: `[arena] LANTERN: 27130 блоков`.

`Hub.prepare(player)` перед каждым стартом и при выходе чистит всё, что
переносится между раундами: инвентарь, здоровье, голод, огонь, уровень и опыт.
Раньше лобби-набор (компас и три иконки режимов) оставался в слотах 4–6
и в следующей игре, а эффекты от прошлого раунда никуда не девались.

## Лобби и комнаты ожидания

Площадь 52×52 (центр 20,20, пол на y=63): круглая мостовая из плит с каймой из
кирпича и тропинками к трём аркам. В центре — жертвенник-костёр на каменном
основании и четыре столба с висящими фонарями; по краю — палый лес (бледные дубы,
тыквы, паутина, черепа на кольях). У каждой арки своя тема: у Фонарщиков — два
костра и папоротники, у Эстафеты — вода и синий огонь, у Двора — крыльцо с бочкой,
полками и свечами.

Раскладка живёт в `core` и говорит строковыми ключами блоков через
`Blueprint`, поэтому её можно:

* поставить в мир — `McBlueprint`;
* отрисовать без клиента — `tools/preview-lobby.sh` строит изометрию настоящими
  текстурами пака: `resourcepack/lobby-lobby.png`, `lobby-lantern.png`,
  `lobby-relay.png`, `lobby-inn.png`.

Комната ожидания (`/h create`) — отдельная площадка 19×19 в центре (0,0):
поляна с кострами и фонарными столбами, развалины часовни или крыльцо трактира.
Раньше здесь был пустой каменный мир, и игроки падали в него из воздуха.

| Проверка | Что сверяет |
|---|---|
| `python3 tools/check_minestom_26_3.py` | ~90 вызовов API — каждый есть в ветке Minestom `26_3` |
| `python3 tools/verify_stubs.py` | 66 типов заглушек, 216 членов (29 унаследованных) — всё есть в Minestom `26_3` / Adventure 5.2.0 |
| `bash tools/build_offline.sh` | ECJ-компиляция `src/main/java` + заглушек и прогон `SelfTest` |
| `python3 resourcepack/tools/check_core_shaders.py` | встроенный lightmap-шейдер объявляет ровно то же, что ванильный 26.3 |
| `python3 tools/check_keys.py` | каждый ключ раскладки → настоящий блок 26.3, свойства без опечаток |
| `python3 resourcepack/tools/verify_26_3.py` | `pack_format` 97 / `[97,0]–[97,1]` и 74 имени текстур клиента 26.3 |
| `python3 shaderpack/tools/check_iris_26_3.py` | только те `gl_*`, которые переписывает Iris 26.3, и только её директивы |

Всё сразу (ресурсы + проверки + офлайн-сборка): `bash tools/make-assets.sh`
(`SKIP_BUILD=1` — без Java-шага).

Подробности и таблица версий — [`COMPAT-26.3.md`](COMPAT-26.3.md).

## Что проверено

* `./gradlew selfTest` — 41 проверку игрового ядра: постройка арен, расход и зарядка фонаря,
  появление Тени и её поимка лучом, передача фонаря, приманка, алтарь и финал, запирание
  комнат, улики, подвал, голосования, победа «не гостя»; плюс мир: нет дыр в площади,
  стена замкнута по всему кругу, у кромки нет полосы пустоты, и каждая арена
  ставит карту **до** того, как позвать `ready()`.
* Слой Minecraft сверен построчно с исходниками ветки `26_3` скриптом
  `tools/check_minestom_26_3.py` (около 90 сигнатур, включая `CompletableFuture`
  у `setInstance`/`teleport`).
* Проект **компилируется** без Gradle: `bash tools/build_offline.sh` — ECJ 3.46.100
  на JRE 25.0.2, 94 файла (`src/main/java` + заглушки), 0 ошибок, затем `SelfTest`
  (41 проверка; 200 прогонов подряд — все зелёные).
* Сами заглушки не «по памяти»: `tools/verify_stubs.py` сверяет каждый их член с
  настоящими исходниками Minestom `26_3` (sha `b7c32f3`) и Adventure 5.2.0,
  включая унаследованные методы (`Player.showTitle` → `Audience`).
* Скачать сам Gradle в песочнице нельзя (см. `COMPAT-26.3.md` → «Сборка без Gradle»):
  закрыты `services.gradle.org`, Maven Central, JitPack. Поэтому `.jar` здесь не
  собирается, но компиляция и тесты — те же, что делает `./gradlew build selfTest`.
