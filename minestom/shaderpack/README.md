# PS1 / PS2 шейдеры «ТРИ НОЧИ»

Два пака под **Iris** или **OptiFine**. Оба делают из картинки 2026 года картинку
1997-го: 15-битный цвет с джиттером, сканлайны, тяжёлая виньетка, холодные тени и
тёплые огни. Полная версия ещё и заставляет геометрию «дрожать», а текстуры — плыть.

```
shaderpack/
├── ps1-lite/shaders/     только экранный проход — безопасный вариант
│   ├── shaders.properties
│   └── final.fsh
├── ps1-full/shaders/     + вершины и аффинные UV
│   ├── shaders.properties
│   ├── gbuffers_terrain.vsh
│   ├── gbuffers_terrain.fsh
│   └── final.fsh
├── ps1-lite.zip
├── ps1-full.zip
├── preview.png           ДО / ПОСЛЕ, посчитано теми же формулами, что в final.fsh
└── tools/
    ├── build.py
    ├── preview.py        честный превью-кадр (не скриншот игры)
    ├── check_iris_26_3.py сверка шейдеров с трансформерами Iris 26.3
    └── iris-26.3.json    кэш списка compatibility-имён
```

## Что делают проходы

**`final.fsh` (оба пака)**

1. **Холодная ночь / тёплый огонь** — яркость гонит цвет к синему в тенях и к янтарю
   на свету: `mix(vec3(0.84,0.90,1.08), vec3(1.08,1.02,0.92), l)`.
2. **Виньетка** `1 - dot(q,q) * 0.60` — тяжёлая, как на CRT в тёмной комнате.
3. **Сканлайны** `0.94 + 0.06*sin(y*π)` — по одной строке, не «сетка».
4. **15 бит на канал** — `floor(col*31 + bayer4)/31`: пять уровней на канал вместо
   восьми, и упорядоченный джиттер, из-за которого градиенты становятся «шахматкой»,
   а не полосами. Это и есть главный признак PS1.

**`gbuffers_terrain.vsh` (только full)**

* вершина прилипает к сетке `viewSize * 0.34` — на ходу мир дрожит и «щёлкает»
  полигонами, ровно как на первой PlayStation без FPU;
* UV уезжают в аффинное пространство (`uv * w, w`), а `fsh` делит обратно —
  текстуры плывут на больших полигонах (affine texture mapping).

## Установка

1. Поставить **Iris** (или OptiFine) для 26.3.
2. Скачать `ps1-full.zip` или `ps1-lite.zip` — прямо с сервера:
   `http://<ip>:8123/shaders/ps1-full.zip` (порт раздачи пака, по умолчанию 8123),
   либо взять zip из этой папки.
3. Положить в `.minecraft/shaderpacks/`, выбрать в настройках графики.

Порядок для полного эффекта: **шейдер + наш ресурспак**. Текстуры 16×16 и 15 бит
дают «плойку» даже без шейдера, шейдер добавляет экранные эффекты.

## Настройка под себя

| Хочу | Что править |
|---|---|
| грубее, «16 бит» | `col * 31.0` → `col * 15.0` в `final.fsh` |
| совсем без сканлайнов | убрать строку с `sin(gl_FragCoord.y * 3.14159265)` |
| меньше виньетки | `* 0.60` → `* 0.30` |
| сильнее дрожание | `* 0.34` в `.vsh` → `* 0.18` (меньше сетка — сильнее снеппинг) |
| без аффинных текстур | в `.vsh` заменить `uvAffine.xy / uvAffine.z` на обычный `texcoord` |

## Совместимость с 26.3: проверено, а не предположено

Iris под 26.3 существует — ветка `26.3` (собирается с `sodium-fabric:0.9.2+mc26.3`).
Наши шейдеры сверены с её трансформерами:

```bash
python3 tools/check_iris_26_3.py
```

Скрипт берёт из исходников Iris 26.3 список compatibility-имён, которые та реально
переписывает, и проверяет каждый идентификатор в наших `.vsh`/`.fsh`:

```
ok  gbuffers_terrain.vsh  (ftransform, gl_Color, gl_MultiTexCoord0,
                            gl_MultiTexCoord1, gl_Position, gl_TextureMatrix)
ok  gbuffers_terrain.fsh  (gl_FragData)
ok  final.fsh             (gl_FragColor, gl_FragCoord)
ok  shaders.properties    (только директивы, известные 26.3)
```

Что это значит построчно:

| Имя | Что с ним делает Iris 26.3 |
|---|---|
| `ftransform()` | переименовывает в `iris_ftransform` и подставляет реализацию |
| `gl_TextureMatrix[0..2]` | заменяет на матрицы Iris |
| `gl_MultiTexCoord0/1` | заменяет на атрибуты текущего пайплайна (Sodium/Vanilla) |
| `gl_Vertex`, `gl_Color` | алиасы позиции и цвета вершины |
| `gl_FragData[0]`, `gl_FragColor` | превращает в `layout (location = 0) out vec4` |
| `varying` | конвертирует в `out`/`in` |

Директивы в `shaders.properties` — `oldLighting`, `clouds`, `sun`, `moon`, `stars`,
`vignette`, `underwaterOverlay` — все разбираются `ShaderProperties` ветки `26.3`,
ничего «оптифайновского по памяти».

Остаётся один риск, который невозможно проверить без клиента: драйвер и конкретный
шейдер-кеш вашей системы. Если пак не стартует — Iris пишет причину в лог, и это будет
сообщение про компиляцию драйвера, а не про несовместимость версии.

`preview.png` — не скриншот игры: сцена собрана из наших текстур и обработана
теми же формулами, что в `final.fsh` (`tools/preview.py`), чтобы было видно,
что именно меняет шейдер. Нижняя полоса — гладкий градиент: слева как есть,
справа — 5 бит + Bayer 4×4.
