# НОЧЬ ФОНАРЕЙ · онлайн-хаб для плейтеста

Три мультиплеерных режима из [`../design/`](../design/README.md), в которые можно
играть **прямо сейчас в браузере**: одна ссылка, имя, код комнаты — и вся компания внутри.

Без зависимостей и без CDN: чистый Node.js + Canvas 2D. Ничего не надо ставить друзьям,
кроме браузера.

```bash
cd party
npm start          # http://localhost:3000
```

Сервер слушает `0.0.0.0:3000` (`PORT` / `HOST` можно переопределить).

---

## Как позвать друзей

1. Ты открываешь ссылку и выбираешь режим → создаётся комната с **4-значным кодом**.
2. В лобби жмёшь **ПОДЕЛИТЬСЯ** — ссылка вида `https://…/?room=4821` копируется в буфер.
3. Друзья открывают ссылку, вводят имя — и попадают в твою комнату. Либо вводят код в поле «КОД» и жмут «ВОЙТИ».
4. Ты (хозяин) жмёшь **НАЧАТЬ ИГРУ**. Остальным готовиться не обязательно — кнопка старта есть только у хозяина.

Если тестируешь один — жми **+ БОТ** / **+ 3 БОТА**: боты играют по тем же правилам и
сразу дают понять, работает ли режим.

> Проверка «на одном компьютере»: обычное окно + окно в режиме инкогнито.
> Одна и та же вкладка не может быть двумя игроками (одно имя, один токен).

## Управление

| Клавиша | Что делает |
|---|---|
| **WASD / стрелки** | идти |
| **Shift** | бежать |
| **E / ЛКМ (держать)** | кормить костёр, заряжать фонарь, тащить гостя, ломать фонарь у алтаря |
| **L** | фонарь вкл/выкл (Фонарщики) |
| **Q** | передать фонарь (Эстафета) |
| **F / Space** | крик-приманка (Эстафета) |
| **V** | показать/скрыть улики (Двор) |
| **мышь** | прицел: луч фонаря смотрит в курсор |

Курсор — это направление света. Поймать Тень можно только если фонарь реально смотрит на неё.

## Что в каждом режиме (кратко)

### Фонарщики · 2–16 · 10 минут
Четыре костра жгут дрова. Носите дрова от куч (подбираются автоматически, когда проходите рядом),
кормите костры, заряжайте фонари. Раз в минуту один из игроков на 30 секунд становится **Тенью**:
фонарь гаснет, и он может погасить костёр. Остальные ловят его лучом.
На рассвете — голосование: **сколько костров дожило, столько человек уйдёт по мосту**.

### Эстафета света · 2–16 · 12 минут
Один фонарь на всех. Носильщик видит лес, остальные — почти ничего. Фонарь садится,
заряжается у костров. **Q** — передать, **F** — крикнуть и отвлечь **Собирателя**, который идёт на свет.
Финал: дойти до часовни и разбить фонарь у алтаря — тот, кто разобьёт, останется в лесу.

### Постоялый двор · 3–16 · 5 циклов × 75 с
Свечи гаснут, комнаты запираются, каждый получает улику (часть — правда, часть — слухи).
Один из вас — **не гость**: он может забрать гостя, если рядом нет свидетелей.
В конце цикла — голосование, кого запереть в подвале. На рассвете — финальное «кто не гость».

## Протокол плейтеста (на один вечер)

Цель — не «понравилось / не понравилось», а **где именно ломается понимание правил**.
Проходим режимы в этом порядке: сначала самый простой для компании, потом сложнее.

### 0. Подготовка (2 минуты)
- [ ] Ты нажимаешь `npm start` (или открываешь превью) и кидаешь ссылку в чат.
- [ ] Все заходят **до** старта: проверить, что в лобби видно всех и у каждого свой цвет.
- [ ] Один раз проверяем связь: у всех внизу слева «● сервер на связи».

### 1. Фонарщики — 10 минут (проверяем базовую петлю)
- [ ] Все понимают, что делать в первые 15 секунд **без объяснений вслух**. Если нет — плохо объясняет HUD.
- [ ] Дрова подбираются, когда просто идёшь через кучу (не надо жать E).
- [ ] У костра с дровами в руках E **кормит**, без дров — **заряжает фонарь**.
- [ ] Костёр можно погасить до конца? Смотрите на полосу «ПОГАС» и на то, что происходит с Тянущимися.
- [ ] Кто-то был Тенью: понял ли он, что делать (баннер «ТЫ — ТЕНЬ»)? Поймали ли его светом?
- [ ] На рассвете все понимают, **кого** и **зачем** выгоняют. Сколько костров — столько мест.
- [ ] Финальный экран объясняет, что произошло.

### 2. Эстафета света — 12 минут (проверяем кооперацию)
- [ ] Носильщик сразу понимает, что фонарь у него (баннер + строка внизу).
- [ ] Передача **Q** срабатывает, когда стоишь рядом; если рядом никого — приходит внятная ошибка.
- [ ] Остальные ощущают слепоту как **напряжение**, а не как баг.
- [ ] Собиратель пугает и его можно отвлечь криком **F**.
- [ ] Все доходят до часовни и понимают, что надо **держать E** у алтаря.
- [ ] Тот, кто разбил фонарь, понимает, что остался (и не считает это багом).

### 3. Постоялый двор — 10 минут (проверяем разговор)
- [ ] Роль «не гость» приходит **только** этому игроку (проверить: остальные не видят).
- [ ] Улики приходят всем, **V** их показывает; никто не путает их с фактами.
- [ ] Запирание комнаты замечено (дверь краснеет, внизу «ЗАПЕРТО: …»).
- [ ] «Не гость» понял, как забирать (нужно E рядом с жертвой и **никого** в радиусе 7).
- [ ] Голосование: кнопки понятны, видно, кто за кого.
- [ ] Финальное голосование «кто не гость» — правила ясны.
- [ ] После раунда все хотят второй.

### 4. Сбор фидбека (по 3 вопросам, письменно)
1. **Где ты не понял, что делать?** (конкретный момент, а не «в целом»)
2. **Что было скучно?** (какая минута тянулась)
3. **Что было страшно/смешно?** (это и есть ядро игры — его усиливаем)

Плюс техническое: лаги, рассинхрон («я был в другом месте»), вылеты, «нажал — не сработало».

### Известные ограничения прототипа
- Нет голосового чата и текстового чата — договаривайтесь в Discord/Telegram (для «Двора» это обязательное условие).
- Нет аккаунтов: имя вводится руками, токен живёт в памяти вкладки. Обновил страницу — зашёл заново.
- Хозяин выходит из комнаты — комната живёт, пока в ней есть люди; если вышел последний, она исчезает.
- Если игрок закрыл вкладку, его персонаж замирает через 2 секунды (но остаётся в игре).
- Мобильный ввод не сделан: нужен WASD и мышь.

## Как это устроено

**Сервер авторитетен**: клиент отправляет только ввод (`mx,my,act,sprint,aim`) и разовые действия
(голос, передача, крик), а рисует исключительно по присланному снимку мира.
Поэтому читерство мышью/скоростью невозможно, а рассинхрона «у меня было иначе» — тоже.

- Тик мира — **50 мс (20 Гц)**, единый для всех комнат.
- Транспорт — **HTTP-поллинг**: клиент шлёт `POST /api/sync` каждые 66 мс (в лобби — 160 мс).
  Никаких WebSocket: работает через любой прокси и в iframe превью.
- Приватность: `snapshotFor(player)` собирает мир **под конкретного игрока** — роль Тени,
  роль «не гостя», улики, свой прогресс видны только владельцу.
- Визуал: тьма — это отдельный слой, из которого радиальными градиентами «вырезается» свет
  (`destination-out`), потом поверх — тёплые ореолы. Поэтому свет здесь — не картинка, а механика.

### API

| Метод | Что |
|---|---|
| `GET /api/rooms` | открытые комнаты + список режимов |
| `POST /api/create` | `{name, mode}` → `{code, id, token, mode}` |
| `POST /api/join` | `{name, code}` → то же |
| `POST /api/ready` | `{code, id, token, ready}` |
| `POST /api/bot` | `{…, count}` — добавить ботов (1–8) |
| `POST /api/start` | `{…}` — хозяин запускает раунд |
| `POST /api/restart` | `{…}` — хозяин возвращает всех в лобби |
| `POST /api/sync` | `{…, input, actions}` → снимок мира |
| `POST /api/leave` | `{…}` |
| `GET /health` | живость + число комнат |

## Тесты

```bash
cd party
npm test
```

- `test/sim.test.mjs` — headless-симуляция: боты играют полные раунды во всех трёх режимах,
  проверяются Тень и её поимка светом, передача фонаря, алтарь, роли и убийство во Дворе,
  запирание комнат, отсутствие `NaN` в снимках.
- `test/client.test.mjs` — клиент в **jsdom** с заглушкой canvas: `app.js` реально
  создаёт комнату, добавляет ботов, стартует и рисует кадры на живых снимках всех трёх режимов;
  отдельно проверяются экраны, HUD, голосование, улики и финальный экран.

`jsdom` берётся из `../web/node_modules`; если его нет — клиентский тест пропускается.
